# 💰 CashFlow Tracker

A Python project using **Pandas** for analyzing, cleaning, and managing personal or business cash flow data.

---

## 🚀 Features

* 📥 **Data Ingestion**: Import and load CSV files.
* 🛠️ **Data Cleaning**: Convert and handle data types (dates, floats, integers).
* 📊 **Analysis**: Filter and process financial transactions.
* ➕ **Custom Metrics**: Generate new calculated columns using `.apply()` and custom functions.

---

## 🛠️ Technologies Used

* **Python** (3.x)
* **Pandas** (Data manipulation and analysis)
